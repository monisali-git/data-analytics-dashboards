## 📌 Dashboards Overview

### 1. 🛒 Amazon India Sales Dashboard — 2025
An end-to-end e-commerce analytics dashboard analyzing Amazon India's 2025 sales performance.

**Key Insights:**
- 📦 Order volume breakdown by Quarter (Q1–Q4)
- 🏆 Top performing product categories
- 🚚 Fulfilment method split (FBA vs FBM)
- 🗺️ State-wise order distribution across India
- 📈 Monthly order trend with interactive chart filters

**Tech:** Chart.js · Vanilla JS · CSS Variables

---

### 2. 🏥 Hospital Emergency Room Dashboard
A clinical analytics dashboard for monitoring hospital ER operations and patient flow.

**Key Insights:**
- 🚨 Patient admission trends and peak hours
- ⏱️ Average wait time and treatment duration KPIs
- 🩺 Case severity distribution
- 📊 Department-wise patient load analysis

**Tech:** Chart.js · Vanilla JS · CSS Grid

---

### 3. 🚢 India Shipping & Logistics Dashboard
A logistics performance dashboard tracking shipment movement across Indian states and carriers.

**Key Insights:**
- 📍 State-level shipping volume heatmap
- 🏎️ Delivery speed & on-time rate analysis
- 📦 Shipment status distribution (Delivered / Pending / Returned)
- 🔍 Carrier performance comparison

**Tech:** SVG Maps · Chart.js · Vanilla JS

---

### 4. 📱 Mobile Handset Sales Dashboard — 2023
A consumer electronics sales dashboard analyzing mobile phone market trends.

**Key Insights:**
- 📊 Brand-wise revenue comparison
- 🏅 Top-selling models and price segments
- 🌍 Regional sales distribution
- 📉 YoY growth trends by brand

**Tech:** Chart.js · Space Grotesk Font · CSS Animations

## 🚀 How to Run Locally

No installation needed — just open in browser:

```bash
# Clone the repo
git clone https://github.com/your-username/data-analytics-dashboards.git

# Open any dashboard
cd data-analytics-dashboards
open amazon_dashboard.html    # Mac
start amazon_dashboard.html   # Windows
```

Or simply **double-click** any `.html` file in your file explorer.

---

## 🌐 Deploy on GitHub Pages (Free Hosting)

1. Go to your repo → **Settings**
2. Scroll to **Pages** section
3. Under *Source*, select `main` branch → `/ (root)`
4. Click **Save**
5. Your dashboards will be live at:
   `https://your-username.github.io/data-analytics-dashboards/`
